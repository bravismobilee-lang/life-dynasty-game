# Life Dynasty Game

Telegram Mini App prototype.

## Demo v0.1
- LDN tap economy (+0.1 per tap)
- progressive silver cost instead of daily tap limit
- mergeable items, levels I–V
- opening items for silver
- silver and premium shop structure
- progression: Бродяга → Рабочий → Специалист → Инвестор → Миллионер → Легенда
- future GRAM integration is shown only as a planned feature

Open `index.html` for a browser preview. State is stored locally for the prototype.
